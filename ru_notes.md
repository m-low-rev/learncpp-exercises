💻 Базовые IT-термины:
1. Source Code (Исходный код) - текст программы которой вы пишете руками
2. Compile / Compiler (Компилировать / Компилятор) - процесс перевода вашего кода в понятные для процессора единицы и нули. Компилятор это программа, которая делает этот перевод.
3. Executable (исполняемый файл) - готовая программа (файл .exe на Windows), которую компьютер может запустить. Результат работы компилятора.
4. Statement (Инструкция / Выражение) - одна законченная строчка кода, которая выполняет действие. В С++ она почти всегда заканчивается точкой с запятой ;.
5. Function (Функция) - именовынный блок кода, который делает определенную задачу. Например, int main() - это главная функция, с которой начинается любая программа на С++.
6. Variable (Переменная) - именованное место в оперативной памяти компьютера (как подписанная коробочка), куда можно положить данные (числа, текст).
7. Value (Значение) - то, что лежит внутри переменной. Например, в строке int waterTemperature = 4; число 4 - это value.
8. Type / Data Type (Тип данных) - указывает компьютеру, что именно лежит в переменной. Например, int —- это целое число, а double - число с плавающей точкой (дробное).
9. Syntax (Синтаксис) - правила грамматики в программировании. Если вы забыли поставить ; или закрыть скобку, компьютер выдаст Syntax Error (синтаксическую ошибку).
10. Debug / Debugging (Отладка / Поиск ошибок) - процесс поиска и исправления ошибок в коде. В реверс-инжиниринге вы будете постоянно использовать программу-отладчик (Debugger), чтобы смотреть, как код работает по шагам.
